# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

这是制茶审评，不是菜谱，也不是饮食记录。

## 审评席规则

- 交评前必须先占用一个审评席；未占席的交评一律拒绝（403）。
- 席位名由审评员在席位册登记，名字唯一；同一时刻一席只能被一名审评员占用。
- 占用、主动离席、强制清席都会写入占席履历（席名、操作者、动作、时刻）。
- 占用超时分钟可改，改完立刻生效；占用超过超时后才允许强制清席（超时设为 0 表示立即可清）。
- 观察员只能查看席位一览与履历，不能登席、占席、清席、改超时。
- 席位有独立专页（顶栏"席位"入口）：上半是当前占用，下半是占席履历。

## 验收

1. taster 登录后看到春茶-A 通过、夏茶-C 不通过。
2. 到"席位"页登记"清香席"并占席，再提交夏茶丙高分，新行出现在表头，页面不整页刷新；未占席直接交评会被拒。
3. 另一会话再占清香席失败；主动离席后再占成功，履历依次看到占用与离席。
4. 把超时改成 0 后可立即强制清席，履历多一条清席；清席后交评再次被拒。
5. observer 登录后没有提交表单，席位页只能看不能操作。
