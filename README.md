# 茶叶拼配审评台

审评员对一个拼配批次打香气、滋味、汤色。服务端按 0.3 / 0.5 / 0.2 加权，7 分及以上通过。提交后只替换表格里新的一行，不整页跳转。

这是制茶审评，不是菜谱，也不是饮食记录。

## 审评席

交评前必须先占用一个审评席：

- 审评员在席位册登记席位，席名唯一；同一时刻一席只能被一人占用。
- 未占席直接交评一律拒绝（403）。
- 占用、主动离席、强制清席都会写入占席履历（席名、操作者、动作、时刻）。
- 占席超时分钟可改，改完立刻约束之后的占用；超时后才允许强制清席。
- 观察员只能查看席位一览与履历，不能登席、占席、清席、改超时。
- 顶栏「席位册」进入席位专页：上半是当前占用，下半是占席履历。
